结论

出圖流程由 12 個步驟組成，真正決定成敗的是出圖前 6 道閘和出圖後 3 層 QA；任何一層唔過都會停，唔會照出。

  1. 6 道閘全部在花錢前執行：Reference 要有已核對原圖、TW 唔當 HK、recipe 要 fit、R10 有 quota、spend 有 server quote、likeness 要掃過。
  2. Prompt 只准 EXACT VISIBLE COPY 上圖；likeness policy 永遠最後，硬上限 19,600 字。
  3. QA 要 7 個 boolean 全 true，packBounds 要實測過關；連續 3 次 fail 會停整個 brand。
  4. 呢頁係 code 對照，不是 live monitoring：冇 uptime、冇即時 probe。
